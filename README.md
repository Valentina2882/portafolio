# Portafolio de Zarella Burbano

Sitio de Zarella Burbano, ingeniera de software en Pasto, Colombia. Es una sola página con sus proyectos, experiencia y contacto.

## Stack

- Next.js 15
- React 19
- Tailwind CSS 4
- TypeScript

## Cómo correrlo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

Publicado en [https://portafoliozare.vercel.app/](https://portafoliozare.vercel.app/).
